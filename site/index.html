Pack Leader

A herdr plugin that lets one coding agent run a team of Claude Code, Codex or pi workers. Each worker gets a task, a tab and a Git worktree. A sidebar shows what each one is doing.

Claude Code / Codex / pi

An independent plugin for herdr. Open source. Runs in your terminal.

Delegate

Mix agents, give each a clear task, and use separate Git worktrees. One coordinator keeps the pack moving.

Supervise

Live status, worker questions and approval gates make blockers visible. Send a followup without hunting through tabs.

Review

Specs, attempts and reports outlive an agent's context window. Inspect the handoffs, then decide what to merge.

A run in herdr

The Pack sidebar

Agent, runtime and state. The task. The last thing the worker said: a heartbeat, a note, a report, or an open question with its choices.

A worker can ask for a decision and wait. The coordinator answers in the usual case; you can step in when you want to. Click a box to select it, click again to open the worker's tab.

The Observer

A second agent under the leader reads the run state and the leader's last turns, then answers you in plain words. It never acts on the run.

Want the leader to know something? Say “pass on: …” and it arrives as a message the leader picks up on its next check.

A worker's tab

Each worker starts in a tab of its own, in its own Git worktree, with a dispatch preamble that spells out the task and how to report. It talks to the leader only through the pack-leader CLI: a report, a question, a note.

The bar on top names the run's goal, the worker's branch and its task. Click it to go back to the leader.

Install

herdr 0.9+ · Node.js 22.18+ · An authenticated agent CLI · Linux or macOS

herdr plugin install zenodea/pack-leader
herdr plugin action invoke install-skill --plugin pack-leader

Example prompt
“Implement CSV import. Give parsing and validation to separate workers in isolated worktrees. Write tests, report back, then review the changes.”

Pack Leader does not merge anything. The coordinator and you review the workers' changes.
