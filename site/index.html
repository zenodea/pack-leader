Lodestar

Lodestar lets one coding agent run a team of others. It hands out tasks, answers their questions and writes down what each one did.

Claude Code, Codex and pi · herdr or tmux, Rex next

Install ↓ View on GitHub ↗

Each dot is an agent. The orange one is in charge: the lodestar, the star the others steer by.

01 · Delegate

You ask once.

Tell your agent what you want, the way you'd tell a colleague: CSV import, parser and validator as separate jobs, tests for both. It splits that into tasks and starts a crewmate for each, with a written spec so nobody has to guess.

lodestar crew start parser --worktree new \
  --spec "Parse CSV input. Add tests. Report back."

02 · Panes

Every crewmate gets a pane of its own.

Crewmates run in their own tabs or splits, and with --worktree new each one gets its own Git checkout on its own branch. Two agents never edit the same file.

Lodestar drives herdr or tmux, whichever you're inside. Rex is next.

03 · Supervise

Stuck crewmates ask instead of guessing.

A crewmate that can't go on asks the leader, with options if it has some, and waits. The others leave notes, escalate, or check in so the leader knows they're alive. One check hands the leader everything that's waiting.

A task is finished when its crewmate says done. A quiet pane doesn't count.

04 · Record

It all gets written down.

Tasks, specs, every attempt, the exact instructions each crewmate got, every report. It lives in a state file outside every agent's context window, so closing a tab or clearing a session loses nothing.

When the leader's own context fills up, it writes itself a note, gets a fresh session and carries on from the note.

lodestar dispatch show d4 --preamble

05 · Merge

Then it puts it all back together.

Each crewmate commits to its own branch. Once the reports are in, the leader reads them, checks the work and merges the branches into main. A branch outlives its crewmate, so nothing is lost if a pane closes first.

Rather merge yourself? Say so, and the leader leaves the branches for you.

06 · Navigator

Talk to it without interrupting it.

Next to the leader sits a second agent whose only job is answering you. Ask what a crewmate is doing, why something's blocked, how close it is. The Navigator reads the run and the leader's recent turns, so the leader never has to stop and explain itself.

Want to change course? Tell the Navigator to pass it on. It lands in the leader's inbox and gets picked up on the next check, not in the middle of whatever the leader is doing.

lodestar say "Leave the docs task for last."

Install

Start a run.

On herdr, it's a plugin:

herdr plugin install zenodea/lodestar
herdr plugin action invoke install-skill --plugin lodestar

On tmux, build it from the repo and install the skill. The install page has the steps, and what tmux can't do that herdr can.

Needs Zig 0.17 to build, an agent CLI you're logged into, and Linux or macOS.

Then tell your agent something like:

Implement CSV import. Give parsing and validation to separate crewmates in isolated worktrees. Have them write tests, review their reports, then integrate.
